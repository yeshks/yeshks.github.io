# yeshks.github.io

This repository hosts my **personal website** powered by **GitHub Pages**.  
It contains the static files that make up the site, including HTML, CSS, JavaScript, and media assets.

## 🚀 Overview

The site is published automatically by GitHub Pages using this repository’s contents and is available at:

https://yeshks.github.io

No build step or backend is required — everything here is served as static content.

## 📁 Repository Structure

- `index.html` — Main homepage of the website
- `css/` — Stylesheets used for layout and design
- `js/` — JavaScript files for interactivity
- `Yesh_Resume.pdf` — Downloadable resume linked from the site
- `.gitignore` — Git ignore rules

## 🛠 Editing the Site

To make changes locally:

```bash
git clone https://github.com/yeshks/yeshks.github.io.git
cd yeshks.github.io
```

## 📦 Deployment

This repository uses GitHub Pages’ default behavior:

- Repository name follows the `username.github.io` convention
- Content is served directly from the main branch
- Updates go live automatically after pushing commits
